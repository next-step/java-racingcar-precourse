# java-racingcar-precourse

##  게임 진행 과정
### 게임 시작
1. 경주할 자동차의 이름을 입력한다. <br/>자동차 이름은 쉼표를 기준으로 구분하며 이름은 5자 이하만 가능하다. 
2. 몇 번의 이동을 할 것인지 입력한다.

### 게임 진행
아래 게임 순서는 사용자가 입력한 이동 횟수만큼 반복하여 진행한다.
1. 모든 자동차는 각자 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상인 경우 전진한다.
2. 모든 자동차가 3번을 진행한 후에는 전진 여부를 출력한다. <br/>이 때, 전진한 경우에는 하이픈(-)으로 표시하고 지금까지 전진한 횟수만큼 누적하여 출력한다.

### 게임 결과
게임 진행이 완료된 후에 가장 많은 하이픈(-)을 가진 자동차의 이름을 출력한다.
만약 해당 자동차가 2대 이상일 경우, 모든 자동차의 이름을 출력한다.
이 때, 자동차의 이름은 쉼표를 기준으로 구분한다.

## 기능
### setCarNames
경주할 자동차의 이름을 입력하고 자동차의 이름들과 전진 횟수를 해시 맵으로 저장하는 기능을 한다.<br/>
먼저 사용자의 입력을 받는다. 입력 받은 값을 쉽표를 기준으로 문자열을 잘라서 리스트에 저장한다.
<br/>리스트를 순회하며 이름이 5자보다 넘는 경우 IllgalArgumentException을 발생시킨다.

### setMoveNum
몇 번 이동할 것인지 입력하는 기능을 한다. <br/>
먼저 사용자의 입력을 받는다. 만약 숫자가 아닌 다른 수가 입력되었을 경우 IllgalArgumentException을 발생시킨다.

### playGame
사용자가 입력한 이동 횟수만큼 반복하여 게임을 진행한다.

### checkMove
모든 자동차별로 isMove 기능을 실행한 후 true가 반환되면 전진 횟수에 1을 더한다.
그 후 getResults 기능 을 실행하여 결과를 출력한다.

### isMove
0에서 9 사이에서 무작위 값을 구한다.
만약 무작위 값이 4 이상인 경우 true를 반환한다.

### getResults
자동차의 전진 여부를 출력한다. 이전 실행 결과까지 누적된 전진 횟수를 출력한다.

### checkMaxMove
모든 자동차들 중 최대로 전진한 자동차의 전진 횟수를 출력한다. <br/>

### getWinner
checkMaxMove 기능을 통해 얻은 횟수와 동일한 횟수를 전진한 자동차의 이름을 출력한다.
여러 명일 경우, 쉼표로 구분하여 출력한다.
